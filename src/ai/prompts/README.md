# 📝 `src/ai/prompts/` - AI Prompt Templates

Contains structured, reusable prompt templates used by the LangChain / Claude client.

## Expected Files:
* `research.prompt.js`: Prompt template instructing Claude on how to perform deep research on lead data.
* `draft-email.prompt.js`: Prompt template for generating personalized SDR outreach emails.
* `classify-reply.prompt.js`: Prompt template for categorizing prospect email responses (e.g., Interested, Not Interested, Out of Office).
