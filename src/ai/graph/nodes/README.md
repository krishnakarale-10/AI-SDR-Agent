# 🧠 `src/ai/graph/nodes/` - LangGraph Step Nodes

Contains discrete processing steps (nodes) executed within the LangGraph State Graph workflow.

## Expected Files:
* `research-lead.node.js`: Feeds prospect information into Claude to generate research insights.
* `draft-email.node.js`: Uses research context to draft hyper-personalized sales outreach emails.
* `classify-reply.node.js`: Analyzes incoming prospect replies to evaluate sentiment and intent.
