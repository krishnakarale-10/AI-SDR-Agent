# 🔔 `src/modules/notifications/` - Notifications Module

Manages real-time and in-app user notifications for events such as email opens, clicks, and positive replies.

## Expected Files:
* `notifications.routes.js`: Endpoints for fetching user notifications (`GET /api/notifications`) and marking them as read.
* `notifications.controller.js`: Handles alert list HTTP requests.
* `notifications.service.js`: Database queries for creating and updating notification states.
